# Dicionario Geral

Feito para organizar meus projetos de maneira mais fácil.

## Padrão de nomenclatura dos projetos

O identificador de cada projeto deve seguir o formato:

```text
P{###}-{CAT}{##}-{ÁREA}
```

### Estrutura do identificador

| Bloco | Descrição | Regra |
|---|---|---|
| `P###` | Número sequencial do projeto | Sequencial global e único. Nunca reutilizar identificadores (P001, P002, P003...). |
| `CAT##` | Categoria e subtipo | As letras representam o contexto do projeto; o número identifica o tipo de entrega. |
| `ÁREA` | Disciplina, tema ou domínio | Código de 2 a 4 letras, definido conforme o dicionário de áreas. |

### Regras gerais

- Cada projeto deve possuir um identificador único.
- A numeração dos projetos é global, independentemente da categoria ou área.
- O código da área deve ser selecionado exclusivamente a partir do dicionário de áreas.
- A estrutura e a ordem dos blocos devem ser preservadas.
